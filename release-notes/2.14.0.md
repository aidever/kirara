云母 Kirara 2.14.0 让追剧订阅能处理站点自己编的季号（例如 TMDB 只有一季，种子却叫 S03E02），并新增新版本检查提醒。

### 追剧：编号映射

- **看得见季号对不上的资源**：「探测制作组」不再悄悄丢弃只差季号的资源。标题和年份都对得上、只是季号不同的种子会单独列在「同名但季号对不上」里，按站点季号分组，显示集数、制作组和站点，可以展开种子核对是哪一集。
- **编号映射**：点「按此映射」或「设置编号映射」，填写「站点 S03 → TMDB 第 1 季」和集数偏移（如 `+40`），可选只对标题含某个关键词的种子生效。规则下方即时显示换算示例。
- **改完立即重新归类**：探测结果缓存 30 分钟，修改映射后直接重新归类，不再逐站重新搜索；命中映射的种子会标出 `S03E02 → S01E42` 这样的换算说明。
- **订阅全程生效**：映射随订阅保存，订阅扫描、手动选种、下载去重和洗版都按换算后的编号处理；扫描时会先按站点编号生成搜索词（如「罗小黑战记 S03E02」）。
- 映射只换算解析出的季/集，不改写种子名；不填规则时与之前完全一致。

### 新版本检查

- 新增「系统设置 → 新版本检查」，默认开启：每 6 小时经全局代理查询 GitHub 上的最新正式版，有新版本时在侧栏顶部提示，点击打开发布页。
- 只提醒，不会自动下载或替换程序；取消勾选后不再访问 GitHub，也可以点「立即检查」。

### 升级

退出旧程序后安装新版，保留原数据目录即可继续使用。已有订阅没有编号映射，行为不变；新版本检查默认开启，不需要时可在系统设置关闭。

Docker 镜像：`ghcr.io/aidever/kirara:2.14.0`；稳定渠道：`ghcr.io/aidever/kirara:latest`。
