云母 Kirara 2.10.0 把「猫眼榜单」扩展为「全球榜单」，并改进了追剧时的制作组探测和站点选择。

### 全球榜单

复刻 MoviePilot 插件 GlobalRankPro，在「自动追剧 → 全球榜单」按来源切换：

- **猫眼**：在实时票房、剧集 / 网剧 / 综艺热度和网络电影之外，新增国内年度票房、影史票房，以及来自 Box Office Mojo 的全球年度票房。
- **Netflix**：官方 Top 10，包括全球榜（英语 / 非英语电影和剧集，含观看次数、观看时长、片长和在榜周数），以及美国、中国香港、中国台湾、日本、韩国、新加坡地区榜。条目按 TMDB 匹配中文片名和海报，配置 TMDB 凭据后可以直接订阅。
- **红果短剧**：官网热播榜、真人剧、漫剧、AI 剧热播榜，显示热度、评分、收藏、题材和简介，可跳转官网观看。
- **音乐**：网易云音乐热歌 / 新歌 / 飙升 / 原创榜、QQ 音乐热歌 / 新歌 / 飙升 / 流行指数榜，以及 Apple Music 热门歌曲，显示名次变化。

红果短剧和音乐榜只供浏览，不做 TMDB 匹配。各来源在后台定时刷新，某个榜单刷新失败时保留上次的数据。

### 追剧

- 创建或编辑订阅时，选好站点后点击「探测制作组」才会探测；打开弹窗或勾选站点不再自动搜索，站点多时不会一下子发出大量搜索。
- 站点选择改为紧凑的标签，显示已选数量。站点较多时可以按名称、类型或网址筛选，只看已选站点，并对筛选结果全选、清空或反选。

### 其他

- 软件内的 GitHub 地址改为 [aidever/kirara](https://github.com/aidever/kirara)。

### 升级

退出旧程序后安装新版，保留原数据目录即可继续使用。数据库会自动增加全球榜单快照表。

Docker 镜像：`ghcr.io/aidever/kirara:2.10.0`；稳定渠道：`ghcr.io/aidever/kirara:latest`。
