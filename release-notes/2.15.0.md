云母 Kirara 2.15.0 修复追剧下载失败后反复重试同一种子的问题，默认接受已播完季的整季包，并同步 PT-depiler 的最新站点定义，新增 Rousi Pro、朱雀、SunnyPT 和 Piggo 等站点支持。

### 追剧

- **HDSky 等站点下载 404**：NexusPHP 站点的 `download.php` 返回 404 或返回的不是种子时，会改从种子详情页取带签名的下载链接再下载。
- **失败的种子不再无限重试**：某个种子多次下载失败后，订阅会记住它，72 小时内改选其他资源，不再反复把同一个种子排进下载队列。订阅详情里显示为「这条资源最近下载失败，暂时改用其他资源」。
- **默认接受整季包**：本季按 TMDB 播出日期已经全部播出（例如 Netflix 一次放出全季、或已完结的季）时，整季包会被正常接受，并一次覆盖本季所有已播集数。本季还没播完时仍不接受整季包，避免把未播的集数误记为已完成；如果某个制作组只发了整季包，探测结果里会说明原因。
- 种子标题里用 `AKA` 连接的两个名字都会参与匹配。

### 站点

- **同步 PT-depiler 站点定义**：站点域名表补全了 PTD 的多域名和旧域名，从 PTD 导入 Cookie 时能认出更多站点（如换了域名的站点）；新增 55 个站点预设，HDChina、HDDolby、TokyoPT、ZRPT 等已换域名的预设改用新地址。
- **新站点类型**：
  - Unit3D：monikadesign、bitporn 等站点可以直接添加。
  - Rousi Pro、SunnyPT：使用站点提供的 API Key。
  - 朱雀（TNode）：使用 Cookie。
  - Piggo：Piggo 改版后不再是 NexusPHP 页面，云母改用站点官方的「实验室 API」。请在 Piggo 个人设置的「实验室令牌」中创建令牌，在站点管理里选择 Piggo 类型并填入。
- 上述站点都支持账户统计、搜索和下载。
- 从 PTD 导入时，云母暂不支持的站点和需要 API Key 的站点会给出具体提示，不再静默跳过。

### 升级

退出旧程序后安装新版，保留原数据目录即可继续使用。已添加为 NexusPHP 类型的 Piggo 站点需要在站点管理里改成 Piggo 类型，并换成实验室令牌。

Docker 镜像：`ghcr.io/aidever/kirara:2.15.0`；稳定渠道：`ghcr.io/aidever/kirara:latest`。
