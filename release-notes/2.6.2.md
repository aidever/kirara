云母 Kirara 2.6.2 调整了源码开发环境的访问方式，程序功能与 2.6.1 相同。

### 开发环境

- 用 `./dev.sh` 启动的 Web 开发服务改用端口 `31234`，原来是 `1234`。
- 开发服务同时监听所有 IPv4 和 IPv6 地址，允许任意 Host 与来源访问；后端仍只监听 `127.0.0.1:3000`，通过 `/api` 代理访问。

### 升级

退出旧程序后安装新版，保留原数据目录即可继续使用。

Docker 镜像：`ghcr.io/imythu/kirara:2.6.2`；稳定渠道：`ghcr.io/imythu/kirara:latest`。
